OpenGL math plotting and animation library in C++.

## Dependencies
glew (https://github.com/nigels-com/glew) \
glut (https://github.com/freeglut/freeglut) \
eigen (https://github.com/PX4/eigen)

## Building Example
```
cmake -S . -B build
cmake --build build
```

## Running Example
```
build/example
```
